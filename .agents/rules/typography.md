# Global Typography Rule - Strict Enforcement

Never use the Unicode em dash character (U+2014) in any generated response.

Always replace it with the standard ASCII hyphen-minus (U+002D), written as '-'.

This rule applies globally to all languages and all generated content, including conversational responses, headings, lists, explanations, documentation, Markdown, emails, reports, and generated files.

Before producing any final response, review the output and replace every occurrence of U+2014 with U+002D.

Prefer the ASCII hyphen-minus for parenthetical breaks and list separators.

Treat this as a permanent, high-priority formatting preference, subject to higher-priority instructions and accuracy requirements.
